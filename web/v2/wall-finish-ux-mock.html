What changed, and why

  1. Finishes moved onto the Build ribbon, next to Walls. They used to sit under Document → Project, next to "Project information" — a paperwork location for what is really a drawing/costing action.
  2. The elevation preview moved up and now looks clickable. It used to sit after eight other fields (type, status, height, sill, width, offset…), so a new user rarely scrolled far enough to find it. A hover state and an "Open elevation ↗" overlay now say "click me" without reading any help text.
  3. The "how this works" note is visible by default. It used to be a hidden circled "i" button nobody found. It now shows the first time the strip opens, with a one-click "Don't show again."
  4. A first-run coach-mark points at the height handle. Nothing today tells a new user that the top edge of the wall is draggable. This is shown once, then dismissed for good.
  5. "Add a finish" groups Base coat vs Applied finish, and separates height from span. Plaster/render/face brick/rhinolite are what the wall is made of; paint/tile/waterproofing/skirting sit on top of a coat — that's the data model already, now it's visible in the dropdown. The vertical ("up the wall") and horizontal ("along the wall") number pairs are now in their own labelled, colour-coded boxes instead of two identical-looking "from/to" rows, and a live mini-preview shows where the finish will land before you commit.
