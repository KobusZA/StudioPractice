Underlay mode bar Mock One bar for every modal underlay tool: what mode you are in, what to do next, how to get out.

Click Set scale, Adjust or Align sheets on the ribbon. Each opens the same bar across the top of the plan, with the mode's name, the current step, its own controls, and Cancel / Done. Esc cancels, Enter confirms, and clicking the lit ribbon button again closes the mode. Starting another mode cancels the current one and says so. Remove asks first and can be undone.

Remove the plan set?

This removes Riverglen concept.pdf from the drawing, including:

  • 2 placed floor sheets and their levels
  • the scale check on Ground floor
  • alignment marks between sheets

Your walls and other drawing are not affected.

What the bar always shows

  • Mode name in the copper pill, matching the lit ribbon button and the copper outline around the plan. The mode shows in three places, so you always know it's on.
  • Step and prompt: "2 of 3 · Click the second point." This replaces the status line, which disappears once you've read it.
  • Mode controls sit in the bar, not in a separate floating panel, so nothing else needs its own close button.
  • Cancel reverts everything done in the mode. Done keeps it. ✕ is the same as Cancel.
  • Snap to PDF lines has a slot already, greyed out until Phase 2 adds it to the point-picking modes.

Per mode

  • Set scale: three steps. A distance field appears at step 3 and Set scale becomes available. "Restart" clears the points.
  • Adjust: opacity, 90° rotation and Pin. When the sheet is pinned it can't be dragged, which stops it moving by accident while you trace.
  • Align sheets: the sheet switcher lives in the bar (✓ = marked), so you never go to the Sheets list mid-task. Mark the same point on each sheet. That can be two floors, or two drawings of one floor (walls on one, something else on the other). The other sheet moves, and shows faintly underneath.
  • Switching modes cancels the current mode and shows a toast saying so, so no change is lost without you knowing. Done shows a toast with Undo.
  • Docked, not floating. The bar sits between the ribbon and the plan, like Revit's options bar, so it never covers the sheet. When no mode is on it falls back to a quiet "Select" line, so its appearance is the signal.
