ISP View — 2D site / schematic

One window for a building or racked access point. Floor draws existing rooms/racks (local units, not Mapbox). Rack is the RU elevation bound to rack_unit. Schematic is generated from live patch + route-trace — not a Visio file. Patchboard stays a fourth action, not a fourth canvas. Create is dual-entry: lists still work; this view is the visual path when ISP is the job. Canvas supplies context; the same create forms / APIs / audit as Rooms & Racks and Equipment.

  • Floor: stack + adds a floor; drag a floor near another to swap. Add room in the toolbar (not by clicking the plan). Drag to move, SE handle to resize. Room + adds a rack.
  • Empty U → chooser: equipment (virtual) or term point (cables can land). Prefills rack + RU.
  • TP geometry is a separate step: snap to host (default) / place on map / leave detached. Never project floor XY to lat/long. Cables, ducts, splices stay map-only.
